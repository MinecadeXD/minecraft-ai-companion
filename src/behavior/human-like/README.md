# Human-like Behavior System

A complete system for simulating human-like behavior in Minecraft bots.

## What It Does

Makes bots behave more like real players through:

### 1. **Natural communication**
- ❌ No canned phrases such as "Got it", "Coming", or "Done"
- ✅ Unique responses generated by an LLM using context
- ✅ Typos and corrections in chat
- ✅ Different typing speeds for each bot
- ✅ Sometimes start typing and then change their minds

### 2. **Probabilistic reactions**
- Found diamonds → 30% say something immediately, 40% stay quiet and mention it later, and 30% say nothing
- Delayed mentions: find something → stay quiet → an hour later: "by the way, I found 5 diamonds"
- They do not spam the chat about every action
- Natural pauses and silence

### 3. **Mood and emotions**
- Fatigue increases over time
- Boredom from repetitive activities
- Excitement when finding things
- Fear when health is low
- Mood affects all behavior

### 4. **Personal goals and initiative**
- They come up with their own activities
- They suggest ideas to the group
- They may disagree with a suggestion
- They debate and discuss plans

### 5. **Human imperfections**
- They forget where they put things
- They sometimes make mistakes (fall, drop the wrong item, or get lost)
- They procrastinate ("I'll do it later", "can't be bothered")
- They get distracted by interesting things
- They sometimes make less-than-optimal decisions

### 6. **AFK and breaks**
- They occasionally go AFK ("sec", "afk", "someone's at the door")
- They return after a realistic amount of time
- Sometimes they take longer than expected
- They do not always explain why

### 7. **Natural descriptions**
- ❌ Avoid: "I'm at coordinates X:123 Y:64 Z:456"
- ✅ Prefer: "west of the base", "deep in a cave", "somewhere nearby"

## Architecture

```
HumanBehaviorController (main)
├── ResponseGenerator (LLM response generation)
├── ProbabilisticReactions (probabilistic reactions to events)
├── TypingSimulator (typing simulation with typos)
├── MoodSystem (mood and emotions)
├── PersonalGoalsSystem (personal goals and initiative)
├── HumanImperfections (mistakes and imperfections)
└── AFKSystem (random AFK periods)
```

## Integration

### Step 1: Initialize Each Agent

```javascript
import { HumanBehaviorController } from './behavior/human-like/index.js';

// Inside the agent class
class Agent {
  constructor(profile, aiBrain, memoryManager) {
    // ... existing code
    
    // Add the behavior controller
    this.humanBehavior = new HumanBehaviorController(
      profile,
      aiBrain,
      memoryManager
    );
  }
  
  async start() {
    // ... existing code
    
    // Start the controller
    this.humanBehavior.start();
  }
  
  stop() {
    // ... existing code
    
    // Stop the controller
    this.humanBehavior.stop();
  }
}
```

### Step 2: Handle Player Commands

```javascript
// Instead of the old template-based code:
async handlePlayerMessage(message, playerName) {
  const intent = FastPlayerIntentRouter.classifyIntent(message);
  
  if (intent !== PlayerIntents.NONE) {
    // Use HumanBehaviorController instead of templates
    const result = await this.humanBehavior.handlePlayerCommand(
      intent,
      message,
      {
        health: this.bot.health,
        food: this.bot.food,
        position: this.bot.entity.position,
        busy: this.currentTask !== 'idle',
        currentTask: this.currentTask
      }
    );
    
    // Send the response through the typing system
    if (result.response) {
      await this._sendMessageWithDelay(result.response);
    }
    
    // Execute the action
    await FastPlayerIntentRouter.executeLocally({
      agentInstance: this,
      intent,
      playerUsername: playerName
    });
    
    return;
  }
  
  // Regular conversation through the AI
  // ...
}
```

### Step 3: Handle Game Events

```javascript
// When finding diamonds, crafting, encountering danger, and so on
async onFoundDiamonds(count) {
  await this.humanBehavior.handleGameEvent(
    'found_diamonds',
    { count },
    {
      busy: this.currentTask !== 'idle',
      recentlySpokeAbout: this.getRecentTopics()
    }
  );
}

async onLowHealth(health) {
  await this.humanBehavior.handleGameEvent(
    'low_health',
    { health },
    {}
  );
}

async onToolBroke(tool) {
  await this.humanBehavior.handleGameEvent(
    'tool_broke',
    { tool: tool.name },
    {}
  );
}
```

### Step 4: Integrate with InterAgentChat

```javascript
// Connect actual message delivery inside HumanBehaviorController._sendMessage

_sendMessage(message) {
  const processed = await this.typingSimulator.processMessage(message);
  
  if (processed.interrupted || !processed.finalMessage) {
    return;
  }
  
  // Send through InterAgentChat with a delay
  await this.interAgentChat.sendMessage(
    this.profile.name,
    processed.finalMessage,
    { delay: processed.delay }
  );
}
```

### Step 5: Add a Quick-Response Method to AIBrain

```javascript
// In ai-brain.js
async generateQuickResponse(prompt, options = {}) {
  const { maxTokens = 30, temperature = 0.9, stopSequences = [] } = options;
  
  // A quick request without context
  const response = await this.provider.generate({
    messages: [{ role: 'user', content: prompt }],
    maxTokens,
    temperature,
    stopSequences
  });
  
  return { text: response };
}
```

## Event Types

Events that can be passed to `handleGameEvent`:

### Discoveries
- `found_diamonds` - { count }
- `found_iron` - { count }
- `found_gold` - { count }
- `found_ancient_debris` - { count }
- `found_village` - { location }
- `found_stronghold` - { location }
- `found_dungeon` - { location }

### Dangers
- `under_attack` - { attacker }
- `low_health` - { health }
- `nearly_died` - { cause }
- `died` - { cause }

### Achievements
- `crafted_important` - { item }
- `built_something` - { what }
- `leveled_up` - { level }

### Routine
- `mining_routine` - {}
- `gathering_routine` - {}

### Miscellaneous
- `tool_broke` - { tool }
- `inventory_full` - {}
- `got_lost` - {}

## Behavior Examples

### Before (with templates):
```
Player: come here
Bot: I'm coming.

Player: where are you?
Bot: I'm at coordinates [X: 123, Y: 64, Z: 456]!

*The bot finds diamonds*
Bot: Found diamonds! X: 12, Y: 11, Z: -45

*The same response every time*
```

### After (with HumanBehaviorController):
```
Player: come here
Bot: coming
*types with a delay*

Player: where are you?
Bot: I'm west of the base, in a cave

*The bot finds diamonds*
*stays quiet*
*20 minutes later*
Bot: by the way, I found 4 diamonds earlier

*or*
Bot: wow, diamonds!

*or says nothing at all*
```
